# Frontend Web Development Projects Collection 🚀

Welcome to my frontend development repository! This project serves as a comprehensive portfolio of practical, interactive web applications built while mastering core client-side technologies. Each application focuses on solving real-world problems, managing state, and integrating external web APIs.

---

## 📁 Project Portfolio

Here is a breakdown of the mini-applications included in this workspace:

### 1. 🌤️ Weather App
* **Description:** A dynamic weather application that fetches real-time meteorological data based on user queries.
* **Key Features:** Live API consumption, error handling for invalid cities, and dynamic weather icon updates.
* **Tech Stack:** HTML5, CSS3, JavaScript (Fetch API).

### 2. 📝 To-Do App
* **Description:** A clean, productive task manager to help users organize daily goals and schedules.
* **Key Features:** Task creation, completion toggles, item deletion, and persistent storage so data isn't lost on refresh.
* **Tech Stack:** HTML5, CSS3, JavaScript (Local Storage API).

### 3. 🔐 Password Generator
* **Description:** A security-focused utility tool designed to generate strong, randomized passwords instantly.
* **Key Features:** Customizable parameter toggles (length, uppercase, numbers, symbols) and a quick 'copy to clipboard' function.
* **Tech Stack:** JavaScript (Math algorithms & DOM manipulation).

### 4. 🔍 Image Finder
* **Description:** A visual search engine that allows users to discover high-resolution photographs via keyword search.
* **Key Features:** Async image loading, grid-based responsive layout, and pagination/infinite scrolling mockups.
* **Tech Stack:** HTML5, CSS3, JavaScript (Async/Await, Unsplash API).

### 5. 👤 GitHub Profile Viewer
* **Description:** A developer utility app that fetches and structures public profile data directly from GitHub.
* **Key Features:** Displays bio, avatar, follower counts, and top repositories instantly upon username input.
* **Tech Stack:** GitHub REST API, JavaScript.

### 6. 🗣️ To-Do with Speech
* **Description:** An accessibility-focused advancement of the classic task manager utilizing voice interactions.
* **Key Features:** Speech-to-text integration allowing users to dictate and log tasks completely hands-free.
* **Tech Stack:** Web Speech API, JavaScript.
